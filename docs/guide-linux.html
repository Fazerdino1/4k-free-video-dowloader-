Compatibilité Linux & CLI Headless

Paquets et recettes de compilation pour postes de travail Wayland/X11, distributions immuables, consoles Linux et serveurs sans interface graphique.

Postes de travail & grand public

Paquets .deb, .rpm et AppImage compatibles Ubuntu LTS, Kubuntu, Xubuntu, Linux Mint, Debian 13, Fedora, Pop!_OS COSMIC, Zorin OS et Elementary OS.

sudo apt install ./4k*.deb || sudo dnf install ./4k*.rpm

Serveurs & Conteneurs Docker

Le binaire vidgrab-cli n'embarque aucune dépendance GTK/WebKitGTK et inclut un Dockerfile multi-stage Alpine musl non-root pour Ubuntu Server, Debian, RHEL, Alma, Rocky et Alpine.

docker build -f packaging/docker/Dockerfile -t vidgrab-cli:latest .

Rolling Release, Gaming & Sécurité

Recettes sources fournies dans packaging/ pour Arch Linux (PKGBUILD), Gentoo (ebuild), Void, Solus, Slackware, Nix Flake, Guix, Flatpak, Snap, Nobara, Bazzite, SteamOS, Kali, Parrot, Tails (proxy Tor auto) et Qubes.

bash packaging/install-linux.sh
